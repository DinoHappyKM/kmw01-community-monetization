想多了解一點

幾個你可能想問的問題。

我一定要從M01全部做完嗎？ ＋

第一次學習可以照順序；平常只想寫一篇文、推一個方案或處理一張報價單，都可以直接選對應模組。

手機和電腦都能用嗎？ ＋

導覽頁按手機與電腦尺寸設計。外掛安裝、產圖額度、檔案下載及私人保存，還要依你的帳號與介面確認；沒有成功的操作，不會說成已完成。

這個網頁會直接幫我做圖或永久記住資料嗎？ ＋

目前是操作導覽與固定範例。實際工作在KMW01完成；私人企劃保存要有可寫位置並回讀確認。這個原型不蒐集或傳送你的輸入。

以後更新，會蓋掉我的品牌資料嗎？ ＋

老師的方法與你的私人企劃分開保存。更新前先備份私人企劃，再依確認過的安裝方式更新，完成後讀回一筆資料確認。正式更新入口仍在準備。
